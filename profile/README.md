## Installation

1. **Join our Discord** for direct loadstring access or latest version announcements: [Discord Server](https://discord.gg/HRRBRpdKrj)
2. **Get the Key** which you can find on our Discord server in `#script-key`
3. **Download** the `.lua` or `.luau` file from the Discord or this repo.
4. **Open** your preferred executor (Delta, Madium, Volt, etc.).
5. **Load** the script and execute.
6. **Enjoy!**
